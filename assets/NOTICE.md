# KJV source text

Source: https://github.com/thiagobodruk/bible/blob/master/json/en_kjv.json
Retrieved 2026-10-19. Source UTF-8 BOM removed and JSON whitespace normalized; verse wording is unchanged in the asset. The display layer removes brace-delimited source annotations and normalizes whitespace.

The repository's code is MIT licensed. The KJV text is generally public domain outside the United Kingdom; UK publication rights are distinct. Review scripture distribution rights for your intended release territories. This is modern-spelling KJV, not an original-spelling 1611 facsimile and not the Allexi adaptation.

Fonts are bundled through the Expo Google Fonts packages (Newsreader and Plus Jakarta Sans), with the licenses distributed in those packages. The pastoral illustration is implemented locally in SVG; it makes no network requests.
